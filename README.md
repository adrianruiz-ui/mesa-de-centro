# Mesa de centro

Guía interactiva para construir una mesa de centro baja (150 × 50 cm, máximo 30 cm de alto) en tres versiones:

- **1A · Bloque y lámina**: bloque de mortero tallado tipo recinto + L de triplay de encino.
- **1B · Piedra real**: el mismo diseño con el bloque forrado de recinto de 2 cm.
- **5A · Puente**: bloque bajo tipo travertino que pasa bajo un plano negro sobre dos patas.

La página incluye modelo 3D (Three.js), planos con cotas, despiece de tableros, alternativas de materiales con tienda y precio (Home Depot, IKEA, Mercado Libre, marmolerías), opciones de armado y lista de compras por tienda.

Precios revisados el 28 de octubre de 2026. Los marcados como estimados son rangos de mercado.

Para verla, abre `index.html` o activa GitHub Pages en la rama `main`.
